# Runner notes

The runner is under `src/app/mock-exams/[formId]` and its results subroute, with UI in `src/components/exam/exam-workspace.tsx`, format/validation/engine/storage in `src/lib/exam/`, and form registration and the fake test fixture in `src/content/forms/`. The QA exporter is `scripts/export-form-for-qa.mjs`; `tests/exam-runner.test.ts` is wired to `npm test`. `src/app/mock-exams/page.tsx` and `src/lib/mount.ts` describe paper availability. `package.json` adds the test script and `tsconfig.json` permits TypeScript import extensions for Node’s test runner. The existing public exam guide already describes the required 2027 SAQ and LEQ format.

The existing `src/proxy.ts` matcher covers `/mock-exams/:path*`. It uses the same `anannt_study_session` cookie check and `gateHref("u2")` redirect to `https://study.anannt.ae/start` as other gated routes. No new auth path is introduced.

Attempts and deadlines are saved in this browser's localStorage, following `src/lib/storage.ts`; there is no server synchronization. Deadlines continue while the page is closed. After expiry the next section starts at the previous deadline; multiple sections can expire before the learner returns. A learner can submit early. Browser storage and clock changes affect this practice runner; it is not an official testing environment. Results use MCQ answer keys and learner-selected rubric points, not automated essay grading. One saved attempt per form can be resumed on this device.

To add a real paper, create `src/content/forms/<form-id>.ts` exporting an `ExamForm` (defined in `src/lib/exam/forms.ts`) with `kind: "full"`, then register it in `src/content/forms/index.ts`; see `qa/FORM-NOTES.md` for the fields and QA export. The registry is empty, and `getForm` rejects fixtures even if one is registered accidentally. Tests import the fake fixture directly. Section durations are fixed in the spec rather than supplied by a form, while validation rejects incorrect counts. Results are shown only after submission or expiry of the final section.
